玻尔模型留下的疑问

玻尔模型解释了氢原子的实验数据，被广泛接受，但它也引出了许多疑问。为什么电子只在由单一量子数 n = 1, 2, 3 等所规定的固定距离上绕轨道运行，而绝不在两者之间？为什么该模型对氢和单电子离子描述得如此之好，却不能正确预言氦或任何更大原子的发射光谱？要回答这些问题，科学家需要彻底改变他们对物质的思考方式。

微观世界中的行为

我们知道物质在宏观世界中的行为——大到肉眼能够看见的物体遵循经典物理学的规律。在台球桌上运动的台球表现得像一个粒子：除非与另一个球或台边相撞，或受到其他力（如摩擦）的作用，否则它将沿直线继续运动。在任一给定时刻，球都有确定的位置和速度（或确定的动量 $\kp = \km\kv$，由质量 $\km$ 和速度 $\kv$ 定义）。换句话说，球沿着一条经典轨迹运动。这是经典物体的典型行为。

当波相互作用时，会呈现干涉图样，台球之类的宏观粒子则不会。例如，水面上相互作用的波可以产生类似图 6.16 所示的干涉图样。这是波在宏观尺度上的行为，很明显，在宏观领域，粒子和波是截然不同的现象。

随着技术的进步，科学家得以更细致地探测微观世界，到 20 世纪 20 年代，越来越清楚的是，非常微小的物质所遵循的规则，不同于我们对大物体所观察到的规则。波与粒子之间毋庸置疑的区分，在微观世界里不再成立了。

物质波：德布罗意波长

最早注意到微观世界这种特殊行为的人之一是路易·德布罗意。他提出了这样的问题：如果电磁辐射可以具有粒子般的特性，那么电子和其他亚微观粒子能否表现出波动特性？在 1925 年的博士论文中，德布罗意把爱因斯坦用来解决光电效应悖论的光的波粒二象性推广到了实物粒子。他预言，质量为 $\km$、速度为 $\kv$（即线动量为 $\kp$）的粒子，也应表现出波的行为，其波长 $\klam$ 由下式给出，式中 h 是我们熟悉的普朗克常量：

$$\klam=\frac{h}{\km\kv}=\frac{h}{\kp}$$

这称为德布罗意波长。与本章讨论过的其他 $\klam$ 值不同，德布罗意波长是粒子和其他物体的特性，而不是电磁辐射的特性（请注意，这个方程中出现的是速度［$\kv$，m/s］，而不是频率［$\knu$，Hz］。这两个符号看起来几乎一样，但含义大不相同）。玻尔曾假定电子是在量子化轨道上绕原子核运动的粒子，而德布罗意认为，如果不把电子看作粒子，而是看作圆形驻波，使得只有整数个波长才能恰好容纳在轨道之内，那么玻尔关于量子化的假设就可以得到解释（图 6.17）。

对于半径为 $\kr$ 的圆形轨道，周长为 $2\pi\kr$，因此德布罗意条件为：

$$2\pi\kr=n\klam,\;n=1,\;2,\;3,\;\ldots$$

发生干涉的电子

德布罗意提出物质的波动性后不久，贝尔实验室的两位科学家 C. J. 戴维孙和 L. H. 革末通过实验证明，电子可以表现出波动行为：他们显示了电子穿过晶体中规则的原子排列时产生的干涉图样。规则排列的原子层起到了狭缝的作用，就像其他干涉实验中使用的狭缝一样。由于要形成干涉图样，充当狭缝的各层间距必须与被测波的波长大小相近，戴维孙和革末便使用晶态镍靶作为他们的“狭缝”，因为晶格内原子的间距与他们所用电子的德布罗意波长大致相同。图 6.18 显示了一幅干涉图样。它与“电磁能”一节中所示的光通过两条靠得很近的狭窄狭缝时的干涉图样惊人地相似。观察在很长一段时间内记录电子碰撞时会发生什么，就可以在图 6.18 中看到物质的波粒二象性。起初，当只记录到少数几个电子时，它们表现出明显的粒子行为，是以看似随机的、局域的小团形式到达的。随着越来越多的电子到达并被记录下来，一幅清晰的干涉图样出现了，这是波动行为的标志。因此，看来电子虽然是微小的局域粒子，它们的运动却并不遵循经典力学所蕴含的运动方程，而是受某种波动方程支配。因此，最初在光子身上观察到的波粒二象性，实际上是所有量子粒子所固有的基本行为。

例 6.6 · 计算粒子的波长

如果一个电子的速度为 1.000 × 107 m s–1，质量为 9.109 × 10–28 g，那么它的波长是多少？

解

我们可以用德布罗意方程来解这个问题，但首先必须对普朗克常量做单位换算。你在前面学过 1 J = 1 kg m2/s2。因此，我们可以把 h = 6.626 × 10–34 J s 写成 6.626 × 10–34 kg m2/s。

$$\klam=\frac{h}{\km\kv}$$ $$\begin{aligned}&=\frac{6.626\times10^{-34}\ \text{kg m}^{2}\text{/s}}{(9.109\times10^{-31}\ \text{kg})(1.000\times10^{7}\ \text{m/s})}\\&=7.274\times10^{-11}\ \text{m}\end{aligned}$$

这是一个很小的值，但比经典（粒子）观点下电子的大小大得多。这个大小与原子的大小处于同一数量级。这意味着电子的波动行为在原子中将是显著的。

学习检测

海森伯不确定性原理

维尔纳·海森伯研究了我们能多精确地测量电子或其他微观粒子的性质这一极限。他断定，同时测量粒子的位置和动量的精确程度存在一个根本的极限。我们对粒子动量测得越精确，就越不能精确地确定它在那一时刻的位置，反之亦然。这被总结为我们现在所称的海森伯不确定性原理：从根本上说，不可能同时精确地确定粒子的动量和位置。对于质量为 $\km$、沿 x 方向以速度 $\kv_{x}$ 运动（或者等价地，动量为 $\kp_{x}$）的粒子，位置的不确定度 $\kdx$ 与动量的不确定度 $\kdpx$ 之积必须大于或等于 $\frac{\hbar}{2}$（其中 $\hbar=\frac{h}{2\pi}$，即普朗克常量除以 2π 的值）。

$$\kdx\times\kdpx=(\kdx)(\km\Delta\kv)\ge\frac{\hbar}{2}$$

利用这个方程，可以算出我们能多精确地同时知道一个物体的位置和它的动量的极限。例如，如果我们改进对电子位置的测量，使位置的不确定度（$\kdx$）取值为，比方说，1 pm（10–12 m，约为氢原子直径的 1%），那么我们对它的动量的测定，其不确定度的值必须至少为

$$\left[\Delta\kp=\km\Delta\kv=\frac{\hbar}{(2\kdx)}\right]=\frac{(1.055\times10^{-34}\ \text{kg m}^{2}\text{/s})}{(2\times1\times10^{-12}\ \text{m})}=5\times10^{-23}\ \text{kg m/s}.$$

ħ 的值并不大，所以像棒球这样的宏观物体，其位置或动量的不确定度小到无法观察。然而，像电子这样的微观物体的质量很小，足以使不确定度变得很大而且显著。

应当指出，海森伯的不确定性原理并不局限于位置和动量的不确定度，它还把其他动力学变量联系起来。例如，当原子吸收一个光子并从一个能量状态跃迁到另一个状态时，能量的不确定度与跃迁所需时间的不确定度也同样相关，即 $\kdE\,\kdt\ge\frac{\hbar}{2}.$

海森伯原理对科学中什么是可知的施加了终极限制。可以证明，不确定性原理是波粒二象性的一个结果，而波粒二象性正是区分现代量子理论与经典力学的核心所在。

原子的量子力学模型

德布罗意发表他的观点后不久——他认为氢原子中的电子与其说是沿量子化圆形轨道运动的粒子，不如说是圆形驻波——埃尔温·薛定谔推广了德布罗意的工作，推导出了今天所说的薛定谔方程。当薛定谔把他的方程应用于类氢原子时，他能够重现玻尔的能量表达式，从而也就重现了支配氢光谱的里德伯公式。薛定谔把电子描述为三维驻波，即波函数，用希腊字母 psi（$\kpsi$）表示。几年之后，马克斯·玻恩提出了对波函数 $\kpsi$ 的一种解释，直到今天仍被接受：电子仍然是粒子，所以用 $\kpsi$ 表示的波并不是物理的波，而是复概率幅。波函数的模的平方 $|\kpsi|^{2}$ 描述了量子粒子出现在空间某一位置附近的概率。这意味着可以用波函数来确定原子中电子的密度相对于原子核的分布。在最一般的形式下，薛定谔方程可以写成：

$$\hat{H}\kpsi=\kE\kpsi$$

$\hat{H}$ 是哈密顿算符，是一组表示量子粒子（如原子中的电子）总能量的数学运算，$\kpsi$ 是该粒子的波函数，可用来求出找到该粒子的概率的特殊分布，$\kE$ 则是该粒子总能量的实际值。

薛定谔的工作，以及海森伯和追随他们脚步的许多其他科学家的工作，通常被统称为量子力学。

理解原子中电子的量子理论

本节的目标是理解电子轨道（电子在原子中的位置）、它们不同的能量以及其他性质。应用量子理论能对这些主题提供最好的理解。这些知识是学习化学键的前导。

如前所述，原子中的电子只能存在于分立的能级上，而不能处于能级之间。这就是说，原子中电子的能量是量子化的，也就是说，它只能等于某些特定的值，可以从一个能级跃迁到另一个，但不能平滑地过渡，也不能停留在这些能级之间。

能级用 n 值来标记，其中 n = 1, 2, 3, …。一般来说，原子中电子的能量随 n 值增大而增大。这个数 n 称为主量子数。主量子数确定能级的位置。它与玻尔原子描述中的 n 在本质上是同一个概念。主量子数的另一个名称是电子层序数。原子的电子层可以设想为从原子核向外辐射的同心圆。属于某一特定电子层的电子最有可能在相应的圆形区域内被找到。离原子核越远，电子层序数越大，因而能级也越高（图 6.19）。原子核中带正电的质子通过质子的正电荷与电子的负电荷之间的静电吸引，使电子轨道趋于稳定。因此，电子离原子核越远，它所具有的能量就越大。

这种关于电子在原子中所处位置的量子力学模型，可用来考察电子跃迁，即电子从一个能级移到另一个的过程。如果跃迁到较高的能级，就吸收能量，能量变化为正值。为了获得跃迁到较高能级所需的能量，原子要吸收一个光子。跃迁到较低的能级则要释放能量，能量变化为负值。这一过程伴随着原子发射一个光子。下面的方程概括了这些关系，它以氢原子为基础：

$$\begin{aligned}\kdE&=\kE_{\text{f}}-\kE_{\text{i}}\\&=-2.18\times10^{-18}\left(\frac{1}{n_{\text{f}}^{2}}-\frac{1}{n_{\text{i}}^{2}}\right)\ \text{J}\end{aligned}$$

nf 和 ni 分别是电子的终态和初态能级。本章上一节中的例 6.5 演示了这类能量变化的计算。

轨道、亚层与径向节点

主量子数是用来表征轨道的三个量子数之一。原子轨道是原子中电子最可能出现的一个大致区域。量子力学模型给出在原子核周围三维空间中找到电子的概率，它以薛定谔方程的解为基础。此外，主量子数确定氢或类氢原子或离子（只有一个电子的原子或离子）中电子的能量，并确定多电子原子和离子中电子分立能级所在的大致区域。

另一个量子数是 l，即角量子数（副量子数、角动量量子数）。它是一个整数，可取值 l = 0, 1, 2, …, n – 1。这意味着 n = 1 的轨道只能有一个 l 值，即 l = 0，而 n = 2 允许 l = 0 和 l = 1，依此类推。主量子数 n 确定轨道的大致大小和能量，而角量子数 l 则规定轨道的形状。l 值相同的轨道构成一个亚层。

l = 0 的轨道称为 s 轨道，它们构成 s 亚层。l = 1 的值对应 p 轨道。对于给定的 n，p 轨道构成一个 p 亚层（例如 n = 3 时为 3p）。l = 2 的轨道称为 d 轨道，接下来是 f、g 和 h 轨道，分别对应 l = 3, 4, 5。

在离原子核的某些距离处，在特定轨道上找到电子的概率密度为零。换句话说，在这个距离上该轨道的波函数 $\kpsi$ 的值为零。半径 $\kr$ 的这种值称为径向节点。轨道中径向节点的个数为 n – l – 1。

考虑图 6.20 中的例子。图中画出的轨道都是 s 型，所以它们的 l 都等于 0。从概率密度的曲线图可以看出，1s（n = 1）有 1 – 0 – 1 = 0 处密度为零的地方（节点），2s 有 2 – 0 – 1 = 1 个节点，3s 轨道有 3 – 0 – 1 = 2 个节点。

s 亚层的电子密度分布是球形的，p 亚层呈哑铃形。d 和 f 轨道则更为复杂。这些形状表示电子可能被找到的三维区域。

取向与简并轨道

磁量子数 ml 规定特定轨道的相对空间取向。一般来说，ml 可以等于 –l, –(l – 1), …, 0, …, (l – 1), l。具有相同 l 值（即在同一亚层中）的可能轨道的总数为 2l + 1。因此，s 亚层（l = 0）中有一个 s 轨道，p 亚层（l = 1）中有三个 p 轨道，d 亚层（l = 2）中有五个 d 轨道，f 亚层（l = 3）中有七个 f 轨道，依此类推。主量子数确定电子能量的大致值。角量子数决定轨道的形状。磁量子数则规定轨道在空间中的取向，如图 6.21 所示。

图 6.22 表示了各种轨道的能级。轨道名称前面的数字（如 2s、3p 等）代表主量子数 n。轨道名称中的字母确定具有特定角量子数的亚层，l = 0 对应 s 轨道，1 对应 p 轨道，2 对应 d 轨道。最后，对于 l ≥ 1，可能的轨道不止一个，每个对应于 ml 的一个特定值。对于氢原子或单电子离子（如 He+、Li2+ 等），n 相同的所有轨道的能量都相同。这称为简并，主量子数 n 相同的能级称为简并轨道。然而，在含有一个以上电子的原子中，这种简并因电子–电子相互作用而消除，属于不同亚层的轨道具有不同的能量，如图 6.22 所示。同一亚层内的轨道仍然是简并的，具有相同的能量。

自旋量子数

虽然前面几段讨论的三个量子数很适合用来描述电子轨道，但一些实验表明，它们不足以解释所有观察到的结果。20 世纪 20 年代已经证明，在极高分辨率下检查氢谱线时，有些谱线实际上并不是单峰，而是成对的、靠得很近的谱线。这就是所谓的光谱精细结构，它意味着即使电子位于同一个轨道，它们的能量之间仍有额外的微小差别。这些观察促使塞缪尔·古德斯米特和乔治·乌伦贝克提出，电子有第四个量子数。他们称之为自旋量子数，或 ms。

另外三个量子数 n、l 和 ml 是特定原子轨道的性质，它们同时确定电子最可能位于空间的哪一部分。轨道是解原子中电子的薛定谔方程的结果。电子自旋则是另一种性质。它完全是一种量子现象，在经典领域中没有对应物。此外，它不能从解薛定谔方程中导出，也与通常的空间坐标（如笛卡儿坐标 x、y 和 z）无关。电子自旋描述的是电子内禀的“旋转”或“自转”。每个电子的行为都像一块微小的磁体，或一个具有角动量的微小转动物体，或一个载有电流的回路，尽管这种转动或电流无法用空间坐标来观察。

电子总自旋的大小只能有一个值，而且电子只能处于两种量子化状态之一进行“自旋”。一种称为 α 态，自旋的 z 分量沿 z 轴正方向。这对应于自旋量子数 $m_{s}=\frac{1}{2}.$ 另一种称为 β 态，自旋的 z 分量为负，$m_{s}=-\frac{1}{2}.$ 任何电子，不论它位于哪个原子轨道中，自旋量子数都只能取这两个值之一。如果施加外磁场，$m_{s}=-\frac{1}{2}$ 和 $m_{s}=\frac{1}{2}$ 的电子的能量是不同的。

图 6.23 说明了这一现象。电子的行为像一块微小的磁体。对于自旋量子数 $\frac{1}{2}$，它的磁矩向上（沿 z 轴正方向）；对于自旋量子数 $-\frac{1}{2}$ 时则向下（沿 z 轴负方向）。当磁体的磁矩与外磁场方向一致时（图 6.23 中左边的电子），其能量较低，而磁矩与外加磁场方向相反时，能量较高。这就是为什么 $m_{s}=\frac{1}{2}$ 的电子在 z 轴正方向的外场中具有略低的能量，而 $m_{s}=-\frac{1}{2}$ 的电子在同一个场中具有略高的能量。即使对于占据原子中同一轨道的电子，情况也是如此。对应于来自同一轨道、但自旋量子数不同的电子的跃迁的一条谱线有两个可能的能量值；因此，光谱中的这条谱线将表现出精细结构的分裂。

泡利不相容原理

原子中的一个电子完全由四个量子数描述：n、l、ml 和 ms。前三个量子数确定轨道，第四个量子数描述电子称为自旋的内禀性质。奥地利物理学家沃尔夫冈·泡利提出了一条一般性原理，它提供了我们理解原子中电子一般行为所需的最后一条信息。泡利不相容原理可以表述如下：同一原子中不可能有两个电子的全部四个量子数完全相同。这意味着，只有当两个电子的自旋量子数 ms 取不同的值时，它们才能共处于同一个轨道（即 n、l 和 ml 这一组量子数相同）。由于自旋量子数只能有两个值 $\left(\pm\frac{1}{2}\right)$，所以同一个轨道最多只能容纳两个电子（而且如果两个电子在同一个轨道中，它们的自旋必须相反）。因此，任何原子轨道都只能被零个、一个或两个电子占据。

指出原子的 n = 4 电子层中亚层的个数、各亚层中轨道的个数，以及这些轨道的 l 和 ml 的值。

解

对于 n = 4，l 可以取 0、1、2 和 3。因此，在原子的 n = 4 电子层中有 s、p、d 和 f 亚层。对于 l = 0（s 亚层），ml 只能是 0。因此只有一个 4s 轨道。对于 l = 1（p 型轨道），m 可以取 –1, 0, +1，所以有三个 4p 轨道。对于 l = 2（d 型轨道），ml 可以取 –2, –1, 0, +1, +2，所以有五个 4d 轨道。当 l = 3（f 型轨道）时，ml 可以取 –3, –2, –1, 0, +1, +2, +3，所以可以有七个 4f 轨道。因此，在原子的 n = 4 电子层中共有 16 个轨道。

例 6.8 · 电子的最大数目

计算能够占据具有（a）n = 2、（b）n = 5 以及（c）n 为变量的电子层的电子最大数目。请注意，你只需考察具有指定 n 值的轨道，而不是那些能量更低的轨道。

解

（a）当 n = 2 时，有四个轨道（一个 2s 轨道和三个标记为 2p 的轨道）。这四个轨道可以容纳八个电子。

（b）当 n = 5 时，需要求和的轨道亚层有五个：

$$\begin{array}{l}\;1\;\text{个标记为}\;5s\;\text{的轨道}\\\;3\;\text{个标记为}\;5p\;\text{的轨道}\\\;5\;\text{个标记为}\;5d\;\text{的轨道}\\\;7\;\text{个标记为}\;5f\;\text{的轨道}\\\underline{+9\;\text{个标记为}\;5g\;\text{的轨道}}\\\;25\;\text{个轨道（合计）}\end{array}$$

同样，每个轨道容纳两个电子，所以这个电子层中可以容纳 50 个电子。

（c）任何电子层 n 中的轨道数都等于 n2。每个轨道中最多可以有两个电子，所以电子的最大数目将是 2 × n2。
