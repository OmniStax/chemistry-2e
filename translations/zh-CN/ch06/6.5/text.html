大小、电离能和电子亲和能

元素周期表中各族（竖列）的元素表现出相似的化学行为。这种相似性的产生，是因为同一族的成员在其价层中具有相同数目和相同分布的电子。不过，元素周期表上的化学性质还呈现出其他规律。例如，沿族向下，原子的金属性增强。位于第 16 族（6A）顶端的氧是无色气体；位于该族中部的硒是半导体固体；而靠近底部的钋是银灰色的固体，能够导电。

沿周期从左到右，每经过一个相继的元素，原子核中就增加一个质子，价层中就增加一个电子。沿族向下经过各元素时，价层中电子的数目保持不变，但主量子数每次增加 1。了解元素的电子结构，使我们能够考察一些支配其化学行为的性质。这些性质随元素电子结构的变化而呈周期性变化。它们是：（1）原子和离子的大小（半径），（2）电离能，以及（3）电子亲和能。

共价半径的变化

量子力学的图像使得很难确定原子的确切大小。不过，有几种实用的方法可以定义原子的半径，从而确定它们的相对大小，所得数值大致相近。我们将采用共价半径（图 6.30），其定义为两个相同原子以共价键相连时两核间距离的一半（这种测量之所以可行，是因为分子中的原子仍然保留着很多原子本身的特性）。我们知道，沿族向下，每经过一个元素，主量子数 n 就增加 1。因此，电子被加到离原子核越来越远的空间区域。所以，随着最外层电子离原子核的距离增大，原子的大小（及其共价半径）必然增大。表 6.2 和图 6.30 以卤素的共价半径说明了这一趋势。整个元素周期表的趋势可见于图 6.30。

有效核电荷

如图 6.31 所示，沿周期从左到右，我们一般发现每个元素的共价半径都比它前一个元素的小。这似乎有违直觉，因为它意味着原子的电子越多，原子半径反而越小。这可以用有效核电荷 Zeff 的概念来解释。它是某一特定电子受到的来自原子核的吸引，其中计入了电子–电子之间的任何排斥。对于氢，只有一个电子，所以核电荷（Z）和有效核电荷（Zeff）相等。对于所有其他原子，内层电子部分地屏蔽了外层电子，使其免受原子核的吸引，因此：

$$Z_{\text{eff}}=Z-\text{屏蔽}$$

屏蔽由另一个电子位于所关注的电子与原子核之间的概率决定，也由所关注的电子所遇到的电子–电子排斥决定。内层电子善于屏蔽，而处于同一价层中的电子对彼此所受核吸引的阻挡则没有那么有效。因此，沿周期每从一个元素移到下一个，Z 增加 1，而屏蔽只略有增加。因此，沿周期从左到右，Zeff 增大。位于元素周期表右侧的电子所受到的更强吸引（更高的有效核电荷）把它们更紧地拉向原子核，使共价半径变小。

因此，正如我们所预期的，最外层的或价电子最容易移去，因为它们的能量最高，受到的屏蔽更多，并且离原子核最远。一般规律是，主族元素形成阳离子时，失去的是构造过程中最后加入的 ns 或 np 电子。另一方面，过渡元素先失去 ns 电子，然后才开始失去 (n – 1)d 电子，尽管按照构造原理，ns 电子是最先加入的。

例 6.12 · 原子半径排序

预测 Ge、Fl、Br、Kr 的共价半径由小到大的顺序。

解

半径沿族向下增大，所以 Ge < Fl（注：Fl 是𫓧的元素符号，𫓧是第 114 号元素，并非氟）。半径沿周期向右减小，所以 Kr < Br < Ge。综合这些趋势，得到 Kr < Br < Ge < Fl。

学习检测

离子半径的变化

离子半径是用来描述离子大小的量度。阳离子总是比母体原子少电子，而质子数相同；它比其母体原子小（图 6.32）。例如，铝原子（1s22s22p63s23p1）的共价半径为 118 pm，而 Al3+（1s22s22p6）的离子半径为 68 pm。当电子从外层价层中被移去后，其余占据较小电子层的内层电子感受到更大的有效核电荷 Zeff（如前所述），被拉得离原子核更近。

电荷较大的阳离子比电荷较小的阳离子小（例如，V2+ 的离子半径为 79 pm，而 V3+ 的离子半径为 64 pm）。沿元素周期表的族向下，我们发现相继元素中电荷相同的阳离子，其半径一般更大，这与主量子数 n 的增大相对应。

阴离子（负离子）是由原子的价层增加一个或多个电子而形成的。这使电子之间的排斥增大，每个电子的 Zeff 减小。这两种效应（电子数目的增多和 Zeff 的减小）都使阴离子的半径大于母体原子的半径（图 6.32）。例如，硫原子（[Ne]3s23p4）的共价半径为 104 pm，而硫离子（[Ne]3s23p6）的离子半径为 170 pm。对于沿任一族向下的相继元素，阴离子的主量子数更大，因而半径也更大。

等电子粒子

具有相同电子构型的原子和离子称为等电子的。等电子粒子的例子有 N3–、O2–、F–、Ne、Na+、Mg2+ 和 Al3+（1s22s22p6）。另一个等电子系列是 P3–、S2–、Cl–、Ar、K+、Ca2+ 和 Sc3+（[Ne]3s23p6）。对于等电子的原子或离子，质子数决定大小。在一系列等电子的离子和原子中，核电荷越大，半径越小。

电离能的变化

使处于基态的气态原子失去束缚最松的电子所需的能量，称为它的第一电离能（$\kIE_{1}$）。元素 X 的第一电离能，是形成带 +1 电荷的阳离子所需的能量：

$$\text{X}(g)\longrightarrow\text{X}^{+}(g)+\text{e}^{-}\qquad\kIE_{1}$$

移去束缚第二松的电子所需的能量，称为第二电离能（$\kIE_{2}$）。

$$\text{X}^{+}(g)\longrightarrow\text{X}^{2+}(g)+\text{e}^{-}\qquad\kIE_{2}$$

移去第三个电子所需的能量是第三电离能，依此类推。从原子或离子中移去电子总是需要能量，所以电离过程是吸热的，IE 值总是正的。对于较大的原子，束缚最松的电子离原子核更远，因而更容易移去。因此，随着大小（原子半径）增大，电离能应当减小。把这一逻辑与我们刚学到的半径知识联系起来，我们预期第一电离能沿族向下减小，沿周期增大。

图 6.33 给出了若干元素的第一电离能与原子序数之间关系的曲线。各元素的第一电离能数值见图 6.34。在一个周期内，$\kIE_{1}$ 一般随 Z 增大而增大。沿族向下，$\kIE_{1}$ 值一般随 Z 增大而减小。不过，这一趋势也有一些系统性的偏差。请注意，硼（原子序数 5）的电离能小于铍（原子序数 4）的电离能，尽管硼的核电荷多一个质子。这可以解释为：亚层的能量随 l 增大而升高，这是由于钻穿效应和屏蔽（如本章前面所讨论的）。在任一电子层内，s 电子的能量低于 p 电子。这意味着，从原子中移去一个 s 电子比移去同一电子层中的 p 电子更困难。铍（[He]2s2）电离时移去的电子是 s 电子，而硼（[He]2s22p1）电离时移去的电子是 p 电子；这使硼的第一电离能较低，尽管它的核电荷多一个质子。因此，每当一个新的亚层开始时，我们都会看到偏离预测趋势的小偏差。

越过半充满亚层之后的下降

当轨道被填充到超过一半时，会出现另一种偏差。氧的第一电离能略小于氮的第一电离能，尽管 $\kIE_{1}$ 值沿周期有增大的趋势。观察氧的轨道表示式可以看出，移去一个电子将消除由 2p 轨道中电子成对所引起的电子–电子排斥，并使轨道成为半充满轨道（这在能量上是有利的）。类似的变化在随后的周期中也会出现（请注意图 6.34 中硫在磷之后的下降）。

例 6.13 · 电离能排序

预测下列过程所需能量由小到大的顺序：Al 的 $\kIE_{1}$、In 的 $\kIE_{1}$、Na 的 $\kIE_{2}$、Al 的 $\kIE_{3}$。

解

从 In 中移去 5p1 电子比从 Al 中移去 3p1 电子更容易，因为 n 更高的轨道离原子核更远，所以 $\kIE_{1}$(In) < $\kIE_{1}$(Al)。从 Al 中电离出第三个电子需要更多能量，因为阳离子 Al2+ 比电中性的 Al 原子对电子的吸引更强，所以 $\kIE_{1}$(Al) < $\kIE_{3}$(Al)。钠的第二电离能移去的是一个内层电子，这是一个比移去价电子高得多的能量过程。综合以上各点，我们得到：$\kIE_{1}$(In) < $\kIE_{1}$(Al) < $\kIE_{3}$(Al) < $\kIE_{2}$(Na)。

电子亲和能的变化

电子亲和能（$\kEA$）是向气态原子加上一个电子以形成阴离子（负离子）这一过程的能量变化。

$$\text{X}(g)+\text{e}^{-}\longrightarrow\text{X}^{-}(g)\qquad\kEA_{1}$$

这一过程可以是吸热的，也可以是放热的，取决于元素。部分元素的 EA 见图 6.35。可以看到，其中许多元素具有 EA 的负值，这意味着气态原子接受一个电子时会释放能量。然而，对于某些元素，原子要变成带负电需要能量，而它们的 EA 值为正。与电离能一样，后续的 EA 值与形成电荷更多的离子相联系。第二个 EA 是向阴离子加上一个电子以形成带 –2 电荷的离子所伴随的能量，依此类推。

正如我们可能预期的，沿一系列原子向前，随着这些原子的有效核电荷增大，加上一个电子变得更容易。我们发现，沿周期从左到右，EA 趋于变得更负。在第 2 族（2A）、第 15 族（5A）和第 18 族（8A）元素中发现的例外，可以根据这些族的电子结构来理解。稀有气体，即第 18 族（8A），具有全充满的电子层，进入的电子必须加到更高的 n 能级上，而这更难做到。第 2 族（2A）的 ns 亚层已充满，所以接着加入的电子进入能量更高的 np，因此，观察到的 EA 值同样不符合趋势所预测的。最后，第 15 族（5A）的 np 亚层是半充满的，接着加入的电子必须与已有的一个 np 电子配对。在所有这些情形中，电子构型原有的相对稳定性都扰乱了 EA 的趋势。

我们还可能预期，每个族顶端的原子具有最负的 EA；它们的第一电离势表明这些原子具有最大的有效核电荷。然而，沿族向下，我们看到该族中第二个元素最常具有最负的 EA。这可以归因于 n = 2 电子层较小，以及由此产生的较大的电子–电子排斥。例如，氯的 EA 值为 –348 kJ/mol，是元素周期表中所有元素里最负的。氟的 EA 为 –322 kJ/mol。当我们向氟原子加上一个电子以形成氟离子（F–）时，是把一个电子加到 n = 2 电子层。这个电子被原子核吸引，但也受到已存在于这个较小价层中的其他电子的显著排斥。氯原子在价层中具有相同的电子构型，但由于进入的电子进入的是 n = 3 电子层，它占据的空间区域大得多，电子–电子排斥减小。进入的电子所受的排斥没有那么大，氯原子更容易接受一个额外的电子，因此 EA 更负。

周期性质与化学反应性

本节讨论的各种性质（原子和离子的大小、有效核电荷、电离能和电子亲和能）是理解化学反应性的核心。例如，由于氟的 EA 在能量上有利，而电离（IE）的能量势垒很大，因此形成氟离子比形成阳离子容易得多。包括导电性和展性（能被加工成薄片的能力）在内的金属性质，取决于具有易于移去的电子。因此，金属性沿族向下增强，沿周期减弱，其趋势与观察到的原子大小的趋势相同，因为移去离原子核较远的电子更容易。
